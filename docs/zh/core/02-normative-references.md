# 第2章 规范性引用文件

---

下列引用文件对于本标准的应用不可或缺。对于注明日期的引用文件，仅所引用的版本适用。对于不注明日期的引用文件，适用引用文件的最新版本（包括任何修订）。

## 2.1 国际标准和规范性文件

### 2.1.1 IREG柏林原则——高等学校排名

**全称**：IREG柏林原则——高等学校排名
**发布机构**：国际排名专家组（IREG）
**发布年份**：2006年（原版）；2016年修订
**与本标准的关系**：IREG柏林原则建立了管辖大学排名设计、实施和发布的16项原则。本标准第4章（原则）与柏林原则保持一致，并将其扩展到所有排名领域。当排名系统属于高等教育评估范围时，符合柏林原则应被视为满足第4章相应的原则级要求，但须遵守本标准规定的附加条款。

### 2.1.2 ISO 20671:2019 — 品牌评估——原则和基本要素

**全称**：ISO 20671:2019 品牌评估——原则和基本要素
**发布机构**：国际标准化组织（ISO）
**与本标准的关系**：ISO 20671规定了品牌评估的原则和基本要素，包括影响品牌实力的法律、行为和财务因素维度。本标准第5章（指标设计）借鉴了ISO 20671建立的维度框架。当排名系统评估品牌价值时，指标体系应与ISO 20671的原则一致，相关扩展模块（SE-02）提供了领域特定的映射。

### 2.1.3 ISO 10668:2010 — 品牌估值——货币品牌估值要求

**全称**：ISO 10668:2010 品牌估值——货币品牌估值要求
**发布机构**：国际标准化组织（ISO）
**与本标准的关系**：ISO 10668规定了货币品牌估值的要求，包括方法（收益法、市场法和成本法）和估值报告的透明度要求。扩展模块SE-02（品牌价值）引用ISO 10668作为品牌排名中货币估值组件的依据。当排名系统将货币品牌估值作为指标或输入时，估值应按照ISO 10668执行。

### 2.1.4 ISO 8000系列 — 数据质量

**全称**：ISO 8000（所有部分）——数据质量
**发布机构**：国际标准化组织（ISO）
**与本标准的关系**：ISO 8000系列建立了数据质量要求，包括准确性、完整性、一致性和时效性等质量特征。本标准第7章（数据采集）采用了ISO 8000的数据质量框架。排名系统中使用的数据应满足ISO 8000适用部分规定的质量特征，详见第7章的进一步规定。

### 2.1.5 ISO/IEC 17021系列 — 合格评定——管理体系审核和认证机构要求

**全称**：ISO/IEC 17021（所有部分）——合格评定——管理体系审核和认证机构要求
**发布机构**：国际标准化组织（ISO）/ 国际电工委员会（IEC）
**与本标准的关系**：ISO/IEC 17021规定了管理体系审核和认证机构的要求，包括审核活动的能力、公正性和一致性。本标准第10章（审计与可追溯性）使排名系统的审计条款与ISO/IEC 17021的原则和要求保持一致。在本标准下开展符合性评估的审计机构应按照ISO/IEC 17021的适用要求运营。

## 2.2 引用框架和公约

### 2.2.1 联合国可持续发展目标（SDGs）

**全称**：变革我们的世界：2030年可持续发展议程（A/RES/70/1）
**发布机构**：联合国大会
**通过年份**：2015年
**与本标准的关系**：联合国可持续发展目标提供了可持续发展的总体框架。扩展模块SE-09（ESG与可持续发展）使ESG和可持续发展排名的指标框架与17个可持续发展目标保持一致。当排名系统评估可持续发展绩效时，其指标应可追溯到相关的SDG目标。

### 2.2.2 联合国教科文组织《保护非物质文化遗产公约》

**全称**：保护非物质文化遗产公约（MISC/2003/CLT/CH/14）
**发布机构**：联合国教育、科学及文化组织（UNESCO）
**通过年份**：2003年
**与本标准的关系**：联合国教科文组织公约建立了识别、保护和促进非物质文化遗产的国际框架。扩展模块SE-05（文化遗产）引用了公约的定义和保护原则。当排名系统评估非物质文化遗产时，其方法论应与公约的精神和条款一致，特别是关于社区参与和文化敏感性的规定。

### 2.2.3 米其林指南方法论

**全称**：米其林指南方法论
**发布机构**：米其林
**与本标准的关系**：米其林指南代表了餐厅和美食评估的一种历史悠久且广受认可的方法论，其特征是匿名的独立检查标准化的评估框架。扩展模块SE-06（餐厅与美食）引用米其林指南方法论作为美食领域独立的、基于专家评估的说明性模型。此引用为资料性引用，不意味着认可或排他性。

## 2.3 ICO标准

### 2.3.1 ICO Std 2001 — 数字产品护照——可信度与质量（DPP-CQ）

**全称**：ICO Std 2001 — 数字产品护照——可信度与质量
**发布机构**：国际交流组织（ICO）
**与本标准的关系**：ICO Std 2001建立了数字产品护照的要求，提供产品品质、来源和可持续性属性的结构化、可验证记录。如0.3.1所述，ICO Std 2002与ICO Std 2001互补运行。当排名系统使用源自符合DPP-CQ记录的數據时，可以依赖ICO Std 2001的数据质量条款来满足本标准第7章的相应要求。

## 2.4 注明日期和未注明日期的引用

以下区分适用于本标准中引用的规范性文件：

a) **注明日期的引用**：当引用文件的特定版本被引用时（如"ISO 10668:2010"），仅该版本（包括本标准发布之前发布的任何修订或勘误）构成规范性引用。注明日期的引用文件的后续修订将在本标准未来修订时考虑纳入。

b) **未注明日期的引用**：当引用文件未指定特定版本时（如"ISO 8000（所有部分）"），适用引用文件的最新版本（包括任何修订）。鼓励本标准的使用者调查采用以下所列未注明日期引用文件的最新版本的可能性。

本标准中注明日期的引用如下：

— ISO 10668:2010
— ISO 20671:2019

本标准中未注明日期的引用如下：

— ISO 8000（所有部分）
— ISO/IEC 17021（所有部分）
— IREG柏林原则——高等学校排名
— 联合国可持续发展目标（SDGs）
— 联合国教科文组织《保护非物质文化遗产公约》
— 米其林指南方法论
— ICO Std 2001（DPP-CQ）
